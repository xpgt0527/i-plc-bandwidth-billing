## IPLC专线是什么？为什么比CN2 GIA贵

一句话：IPLC是点对点的物理专线，两端固定，链路自成一体，不走公网路由。CN2 GIA、163骨干网本质上还是走公共互联网，只是路由质量不同，晚高峰该堵还是堵；IPLC从入口机房到出口机房这段是物理直连，不受公网拥堵影响。

它的优势集中在三点：延迟稳定，不会晚高峰掉速；带宽独享或可控，不被别人挤；链路不经过公网节点，安全性和私密性更好。行业里通常把它视为出海线路的性能天花板，贵也贵在这里。

看价格和测速之前，先搞清楚一个概念：**端内延迟**。商家标注的延迟（比如沪日25~28ms）指的是专线两端机房之间这一段，你实际感受到的延迟还要加上本地到入口机房、出口机房到目标服务器这两段。所以拿25~28ms直接当成游戏或直播的全程延迟去预期，会失望。

常见线路的端内延迟参考值如下：

| 线路 | 端内延迟参考 |
| --- | --- |
| 深港IPLC / 广港IEPL | 1~2ms |
| 沪港IPLC | 21ms左右 |
| 沪日IPLC | 25~28ms |
| 沪美IPLC | 124~134ms |

地理距离摆在那，港方向1~2ms，到日本25ms上下，到美国就得120ms以上，这是物理规律，哪家都压不下去。

## IPLC专线多少钱？先把两种计费方式的账算清

行业一般报价是：独享带宽按M计费，300~500元/M/月，越靠近香港越便宜，越远（比如美国）越贵；流量计费折算下来大约0.5~1元/GB。注意这是裸线路的价位，市售套餐通常是“线路+云服务器”打包，会再叠一层CPU、内存、硬盘的配置成本。

实际到具体产品上，单位成本差距很大。以MKCloud沪日流量版为例，用月付价除以月流量算一下：

- 500GB档228元 → 约0.46元/GB
- 1TB档358元 → 约0.35元/GB
- 2TB档568元 → 约0.28元/GB
- 4TB档998元 → 约0.24元/GB
- 6TB档1388元 → 约0.23元/GB
- 10TB档和20TB档 → 都在0.22元/GB上下

档位越大单价越低，大流量档已经做到行业一般报价区间的一半以下。

独享带宽版换个算法。MKCloud沪日独享带宽版从5M的700元/月到100M的8500元/月，折算每M每月在85~140元之间，而且这个价格里含一台云服务器的配置。对照行业300~500元/M/月的裸线路报价，把服务器成本算进去它仍然明显更低。这也是它价格表值得细看的原因。

独享版划不划算，取决于你能不能把带宽跑满。拿5M独享举例，7×24小时跑满的理论上限约1580GB/月，折合约0.44元/GB，还不限量。跑得满，独享版相当于无限流量；跑不满，流量计费更省钱。

简单归纳：

- 月流量1TB以内、用量波动大 → 选流量版
- 长期大流量、带宽需要保底（直播推流、持续数据同步）→ 选独享版
- 美国方向的大流量需求 → 直接看后面的IXP版，那里有更低的单价

## 下单前确认的几件事

1. **延迟预期**：商家标的都是端内延迟，算体验时把你本地到入口机房那段加进去，沪日业务全程延迟落在几十毫秒属于正常。
2. **先小档试跑**：表列价格均为月付，先从低档位起步，确认线路质量符合预期再升档，比一上来就锁大档稳妥。
3. **主备线路**：条件允许的话主用一条、备用一条，最好来自不同商家、不同线路走向，避免单点故障把业务全押在一条线上。
4. **比价基准**：看到任何报价，先拿行业区间衡量——独享带宽300~500元/M/月、流量约0.5~1元/GB。腾讯AIA、阿里CEN、华为IPLC这类大厂产品官网定价很高，市场上多为代理商转售，报价差异大，别拿官网价直接对比。
5. **流量余量**：用量估不准时宁可选大半档。电信入口版超量软限速，IXP版超量直接停机，高峰期被动降速往往比多花几十块更难受。

## 常见问题

**IPLC和IEPL有什么区别？**

IPLC是物理层点对点专线，传统运营商产品，走TDM/E1传输；IEPL是以太网层专线，带宽调度更灵活、扩容更方便。两者实际体验接近，IEPL通常便宜一些。选哪个别纠结缩写，看具体线路的落地延迟和带宽稳定性。

**沪日IPLC延迟多少？**

端内延迟25~28ms。完整链路延迟还要加上本地到上海入口机房、日本出口到目标服务器这两段。

**沪美延迟120多毫秒，为什么还有人用？**

上海到美国的物理距离决定了这个数字，任何线路都一样。沪美的优势是带宽成本，同样的预算能买到更大的带宽和流量，对数据同步、备份、中转这类业务来说延迟不敏感，带宽和流量才是刚需。

**流量用完了会怎样？**

分线路：上海电信入口的流量版软限速，超量后降速继续跑；沪美IXP版超量停机，下个周期才恢复。
